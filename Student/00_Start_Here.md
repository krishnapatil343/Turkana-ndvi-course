# North Turkana NDVI practical

Allow 6–8 hours after Earth Engine access is working. Begin with [What is NDVI?](01_What_is_NDVI.md) and the [entry check](02_Entry_Check.md). Then open the Word guide and the Background and script walkthrough. Download the starter script and workbook from the Student folder. Draw a documented rangeland point in the Code Editor. Use the instructor's coordinates if supplied. Download your own CSV from Google Drive after running the export.

| File | Purpose |
|---|---|
| Word guide | Numbered practical and submission requirements |
| Background and script walkthrough | NDVI concepts, product specifications, login and checkpoint explanations |
| Monthly_rain_ndvi.js | Copy into the Code Editor after drawing the point named geometry |
| NDVI_lag.xlsx | Paste rainfall and NDVI in chronological order and compare the lag results |
| Interactive_Map.js | Optional Code Editor demo after the core lab |

Submit one report up to three pages, your script and completed workbook. Include coordinates and a buffer screenshot, rainfall and NDVI time series, raw and anomaly lag results with pair counts, and a short interpretation.
